# MemorySimulation

Bu proje, bellek ve ağ kartı gibi sistem bileşenlerini görevler üzerinden modelleyen bir simülasyondur.

**Odak konular:** görev/sınıf modelleme, thread ve Runnable tabanlı işler, bellek okuma-yazma görevleri ve eşzamanlı işlem kavramları. Kaynak klasöründe Java kaynakları yerine derlenmiş `.class` dosyaları bulunmaktadır.
