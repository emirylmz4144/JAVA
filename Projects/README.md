# Java Projects

Bu dizin, belirli bir Java konusunu tek başına göstermekten ziyade gerçek bir kullanım senaryosunu çözen bağımsız uygulamaları içerir.

Projeler uygulamanın kapsamı, bileşen sayısı, veri yönetimi ve mimari karmaşıklığına göre seviyelendirilmiştir. Sınıflandırma mutlak bir kalite ölçütü değil, mevcut kod tabanına göre yaklaşık bir zorluk ayrımıdır.

## Kategoriler

- **Basic:** Sınırlı kapsamlı, temel iş akışlarına sahip küçük uygulamalar.
- **Intermediate:** Birden fazla sınıf/bileşen, iş kuralları ve daha kapsamlı kullanıcı akışı içeren uygulamalar.
- **Advanced:** Daha kapsamlı işlevler, veri erişimi veya daha belirgin mimari ayrımlar içeren uygulamalar.

Java konularını tek tek anlatan küçük örnekler (Lambda, Functional Interface, Thread, Generics vb.) bu dizine değil, ana Java konu klasörlerine aittir.
