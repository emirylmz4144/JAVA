# FiltringPersonWihtFunctInterfaceAndLamda

Bu proje, Java'da **Functional Interface** ve **Lambda Expressions** kullanımını gösterir. Kişi listesinin özel bir koşula göre filtrelenmesi, davranışın parametre olarak aktarılmasıyla gerçekleştirilir.

**Odak konular:** `@FunctionalInterface`, özel fonksiyonel arayüz, lambda ifadeleri, davranış parametresi ve liste üzerinde filtreleme.
